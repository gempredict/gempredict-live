# Phase 5J catalog identity evidence

Use the immutable protected Phase 5J Preview with the existing owner diagnostics, library and marketplace settings scoped to `feature/catalog-evidence-foundation-phase5j`. Open a report and expand **Identity evidence**. The view derives version 1 evidence from existing report fields, including older My Card Library reports. It needs no migration and does not rewrite historical reports.

The result distinguishes AI and saved proposals, owner review, model-read photo observations, and claims supported by independent catalog records. It retains field disagreements and checks that a single catalog record accounts for the combination of claims. Matching a record supports identification at the catalog level. Independent physical comparison is still required to verify an exact printing, including the photographed Ohtani #700.

Future catalogs may supply normalized claims through a reviewed in-process adapter with a source, provenance, record identifier and source revision or retrieval timestamp. Untrusted JSON and marketplace titles cannot create approved evidence. No sports catalog, physical-verification adapter or new provider integration is configured. The existing pinned TCGdex receipts supplement Pokémon evidence only where the receipt is already validated. Generated hosted flags are not treated as definitive negative printing evidence.

The market endpoints return a temporary versioned evidence summary for Phase 5J. It does not authorize a financial calculation, create a completed-sales catalog crosswalk, or change a marketplace request or entitlement.
