# Phase 3J — premium collector report

## Scope

Presentation only, on the reconciliation branch. The actual `ResultCard` used by real
scans and protected owner demos now has a charcoal/gold collector layout. No AI,
identity, catalog, condition normalization, matching, completed-sales qualification,
licensing, fee, economics, owner-authentication or Production configuration is changed.

## Design

- Compact card hero: complete subject/collector number, canonical year/set, explicit
  unverified printing, concise identity badge and the existing session-only photo viewer.
  No fabricated artwork. Missing photos use a compact availability disclosure. Original
  AI identity and all verification dimensions remain in identity/provenance details.
- Five touch-friendly section links. Four condition tiles show existing conservative
  states, concise side-specific findings and qualifications. Detailed Condition Findings
  retains actual regions, cues, certainty, limitations, inspection coverage and original
  evidence. No whole-card cleanliness, score, grade or probability is inferred.
- Up to the existing six safely screened active candidates. Each asking amount stays
  beside an unverified-printing label; normal listings retain validated source URLs and
  available images. Synthetic listing links and images remain disabled. Empty listings
  have one short message; rejection counts and explanations are expandable.
- Raw/PSA 8/9/10 remain separate. No qualified feed produces one shared unavailable
  message and compact cohort labels, never four large empty cards or zero prices.
  Existing qualified fixture tests exercise separate medians, counts and date ranges;
  permitted transaction details, rights restrictions and history limits stay accessible.
- A compact PSA outlook explains missing verified sales/printing evidence. Existing
  manual arithmetic remains secondary inside a disclosure, with a light inner surface
  for legibility of the unchanged calculator. Financial gates and calculations are intact.
- One prominent synthetic ribbon, plus small synthetic badges adjacent to observations,
  listings and market evidence. Owner/demo explanation is expandable. Example selection
  is compact; both card categories still use the exact same report components.

## Presentation deduplication

`distinctConditionRows()` removes only equivalent full observations (stable key order,
whitespace normalization). Different side, region, cue, certainty or provenance remains
separate. `conditionSnapshot()` combines otherwise identical localized observations
into a single issue with its region list/count. All materially different evidence stays
available; source arrays are not mutated. Original evidence, including original source
rows, is retained in the technical disclosure and unchanged saved/copied reports.

This is not a condition-engine correction. The existing three synthetic back-corner
findings remain three distinct proposed locations, shown as one issue across three
regions rather than three identical paragraphs. Actual defect detection accuracy has
not been measured by these synthetic tests.
