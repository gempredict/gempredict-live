# Phase 5H marketplace Preview

Use `/card-sales-pilot` on the immutable protected Phase 5H Preview. Scope the existing Phase 5G marketplace, Preview owner diagnostics, and isolated library bindings to `feature/variation-match-accuracy-phase5h`.

The reviewed parallel and optional observed photo pose are used for this lookup only. A listing can support those characteristics, conflict with them, or leave them unknown. For example, a seller's explicit factory complete-set designation conflicts with a reviewed regular base card. A generic reference to completing a set does not. The pilot does not authenticate a physical printing from a listing title or owner review.

The grade label reflects explicit listing or provider evidence. With no raw or grading evidence, the status remains unknown even on a Raw search. The Card API results retain the same temporary, owner-only evaluation terms and Phase 3G qualification gates.
